## Drivers & Data Ingestion

| Repository | Description |
|------------|-------------|
| [mqttsubscribe](https://github.com/weewx-contrib/mqttsubscribe) | WeeWX driver and service that subscribes to MQTT to receive data. |
| [weewx-data-ingest](https://github.com/weewx-contrib/weewx-data-ingest) | Data ingestion extension (fork of Millardiang/weewx-data-ingest; no description provided). |
| [weewx-ecowitt_local_http](https://github.com/weewx-contrib/weewx-ecowitt_local_http) | WeeWX driver for devices that support the Ecowitt local HTTP API. |
| [weewx-ecowittGateway](https://github.com/weewx-contrib/weewx-ecowittGateway) | Fully featured, maintained replacement/alternative to weewx-ecowitt_local_http. |
| [weewx-gw1000](https://github.com/weewx-contrib/weewx-gw1000) | WeeWX driver based on the Ecowitt LAN/Wi-Fi Gateway API. |
| [weewx-rtldavis](https://github.com/weewx-contrib/weewx-rtldavis) | Unified weewx-rtldavis sources and installer. |

## MQTT & Data Publishing

| Repository | Description |
|------------|-------------|
| [broadcastWeatherFlowUDP](https://github.com/weewx-contrib/broadcastWeatherFlowUDP) | Broadcasts sensor readings in a WeatherFlow UDP API compliant format. |
| [mqttpublish](https://github.com/weewx-contrib/mqttpublish) | WeeWX service that publishes data to MQTT. |
| [mqttreplicate](https://github.com/weewx-contrib/mqttreplicate) | Extension that uses MQTT V5 request/response to replicate databases. |

## Sensors

| Repository | Description |
|------------|-------------|
| [sds011-mqtt](https://github.com/weewx-contrib/sds011-mqtt) | Outputs SDS011 particulate matter sensor readings to MQTT. |
| [weewx-NovaSDS011](https://github.com/weewx-contrib/weewx-NovaSDS011) | WeeWX 5.1 service for the Nova SDS011 particulate sensor; injects real-time PM2.5 and PM10 values. |

## Skins & Dashboards

| Repository | Description |
|------------|-------------|
| [jas](https://github.com/weewx-contrib/jas) | WeeWX skin that uses Apache ECharts to chart data. |
| [weewx-Belchertown-MQTT-Cloudflare-Tunnel](https://github.com/weewx-contrib/weewx-Belchertown-MQTT-Cloudflare-Tunnel) | HTML resources for using the Belchertown skin with MQTT over a Cloudflare Tunnel (no description provided). |
| [weewx-divumwx](https://github.com/weewx-contrib/weewx-divumwx) | Comprehensive dashboard skin for WeeWX 5.4.0+ using D3.js for charts, gauges and dynamic images. |
| [weewx-ecowitt_console_emulator](https://github.com/weewx-contrib/weewx-ecowitt_console_emulator) | Skin extension that emulates an Ecowitt console display, responsive to all screen sizes. |

## Gauges & Charts

| Repository | Description |
|------------|-------------|
| [stackedwindrose-extension](https://github.com/weewx-contrib/stackedwindrose-extension) | Generates a polar windrose plot of wind speed and direction. |
| [weewx-carbonsteel-series](https://github.com/weewx-contrib/weewx-carbonsteel-series) | Rework of weewx-steelseries using D3.js and a realtime.json feed; works standalone or with Seasons and New-Belchertown skins. |
| [weewx-realtime_gauge-data](https://github.com/weewx-contrib/weewx-realtime_gauge-data) | Near real-time updating of SteelSeries Weather Gauges. |
| [weewx-stackedwindrose26](https://github.com/weewx-contrib/weewx-stackedwindrose26) | Modern D3-rendered version of the stacked windrose extension (WeeWX 5+ only). |
| [weewx-steelseries](https://github.com/weewx-contrib/weewx-steelseries) | WeeWX extension to install the SteelSeries Weather Gauges. |
